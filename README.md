# QVirtualScroll
> Simple Quasar component that displays any data in virtual scroll table with draggable and resizable columns

## Install
````bash
$ npm install git+https://github.com/flespi-software/QVirtualScroll.git --save
````

## [Component API and structures](docs/ComponentAPI.md)

## Requirements:

- [Node.js](https://nodejs.org/en/) (>=18.x)
- npm version 6+ and [Git](https://git-scm.com/).
- [Quasar](https://quasar.dev/) (^2.16.0)
- [Vue](https://vuejs.org/) (^3.4.18)
